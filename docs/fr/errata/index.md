# Anomalies connues

Cette page recense toutes les anomalies matérielles connues des différentes versions de HALMET.

## Version 1.0.0

Les entrées numériques 3 et 4 sont inversées sur la sérigraphie de la face arrière. Le brochage correct est le suivant :

  - DI3 : GPIO 27
  - DI4 : GPIO 26
