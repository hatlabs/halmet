# Errata corrige

Questa pagina elenca tutti i difetti hardware noti delle diverse revisioni di HALMET.

## Versione 1.0.0

Gli ingressi digitali 3 e 4 sono invertiti nella serigrafia sul retro della scheda. La piedinatura corretta è:

  - DI3: GPIO 27
  - DI4: GPIO 26
