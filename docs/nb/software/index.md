# Programvare

## Innledning

Som utviklingskort leveres HALMET uten forhåndsinstallert programvare. Du må installere egnet programvare selv. Dette er ikke vanskelig, men noe erfaring med mikrokontrollerkort som Arduino eller ESP32 Devkit er anbefalt.

Eksempelfirmware for HALMET finnes i [GitHub-repositoriet HALMET-example-firmware](https://github.com/hatlabs/HALMET-example-firmware).

Vær oppmerksom på at vi bare gir støtte for spørsmål om programvareutvikling gjennom [diskusjonsforumet til Hat Labs](https://github.com/hatlabs/discussions/discussions).

Flere instruksjoner kommer snart.
