# Kjente feil

Denne siden lister opp alle kjente maskinvarefeil i de ulike HALMET-versjonene.

## Versjon 1.0.0

Digitale innganger 3 og 4 er byttet om på silketrykket på undersiden. Riktig pinnebelegg er:

  - DI3: GPIO 27
  - DI4: GPIO 26
