# Bekende fouten

Op deze pagina staan alle bekende hardwarefouten in de verschillende versies van de HALMET.

## Versie 1.0.0

De digitale ingangen 3 en 4 zijn in de opdruk aan de achterzijde verwisseld. De juiste pintoewijzing is:

  - DI3: GPIO 27
  - DI4: GPIO 26
