# Tunnetut virheet

Tällä sivulla luetellaan kaikki tunnetut laitteistoviat HALMETin eri versioissa.

## Versio 1.0.0

Digitaalitulot 3 ja 4 ovat vaihtaneet paikkaa kortin takapuolen silkkipainossa. Oikea nastajärjestys on:

  - DI3: GPIO 27
  - DI4: GPIO 26
