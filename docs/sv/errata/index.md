# Kända fel

Den här sidan listar alla kända hårdvarufel i HALMETs olika versioner.

## Version 1.0.0

De digitala ingångarna 3 och 4 är förväxlade i monteringstrycket på undersidan. Rätt stiftindelning är:

  - DI3: GPIO 27
  - DI4: GPIO 26
